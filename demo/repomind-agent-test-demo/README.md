# RepoMind Agent Test Demo

用于测试 RepoMind Code Agent 的多类型故障定位能力。

测试场景：
1. npe-demo - NullPointerException 根因分析
2. logic-bug-demo - 业务逻辑错误分析
3. call-chain-demo - 多层调用链分析
4. python-bug-demo - Python 空值错误分析
5. config-demo - 配置错误分析

建议问题：
- 为什么 OrderService.createOrder 出现 NullPointerException？
- 为什么订单价格计算错误？
- 为什么用户注册失败？
- 为什么 Python login 接口报错？
- 为什么数据库连接失败？
