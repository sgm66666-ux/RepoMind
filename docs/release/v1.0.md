# RepoMind v1.0 · 本地作品集发布基线

日期：2026-09-24。此文档记录当日的本地运行与演示基线，不代表远程发布或生产 SLA；全新克隆验证不包含在这次运行记录中。

## 架构与能力

Vue 3 控制台经 Spring Boot 网关调用 FastAPI。FastAPI 使用 tree-sitter 为 Java/Python 建立 Symbol、Relation 与已解析 CALLS 图；TaskPlanner 提供任务方向，AgentLoop 让本地 Ollama `qwen2.5-coder:14b` 选择真实 Tool，执行策略限制重复/无进展与步数/超时。Verified Evidence Store 区分真实 Observation、独立标记的 AST 图路径与模型推断；FinalDiagnosis 投影/校验过滤未经证实的文件、行号、源码和调用边。CodeContextBuilder 提供受限代码上下文，不将整个仓库直接交给模型。
